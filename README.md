# React + Vite

Proiect React gol, cu structura de pornire a unui proiect Vite + React.

## Pornire

```bash
npm install
npm run dev
```

Deschide http://localhost:5173 în browser.

## Scripturi

- `npm run dev` — pornește serverul de dezvoltare
- `npm run build` — compilează pentru producție în `dist/`
- `npm run preview` — previzualizează build-ul
- `npm run lint` — rulează ESLint

## Structură

```
react-starter/
├── public/vite.svg      # fișiere statice
├── src/
│   ├── assets/react.svg
│   ├── App.jsx          # componenta principală
│   ├── App.css
│   ├── main.jsx         # punctul de intrare
│   └── index.css        # stiluri globale
├── index.html           # pagina HTML de bază
├── vite.config.js
├── eslint.config.js
└── package.json
```
